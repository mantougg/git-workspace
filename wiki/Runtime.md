# Runtime 工作台

不打开 IntelliJ / VS Code，直接构建、运行、停止并监控 Spring Boot 与 Node.js 服务。面向测试、联调、运维等「不需要写代码」的角色，以及 AI 辅助流程。

## 工具链管理

- **JDK 管理**：扫描本机 JDK、手动添加、按应用绑定版本——构建与运行保证同源 JDK；
- **Maven 设置**：`mvn` / `mvnw` 检测，支持 **mvnd 守护进程与构建缓存**加速；
- **Node 工具链**：检测 node 及 nvm / fnm / volta / mise 等版本管理器，包管理器决策链 npm / pnpm / yarn。

工具链缺失时不会硬失败，而是给出可行动的提示（装什么、怎么装）。

## Spring Boot 应用

- **Maven/POM 发现**：扫描工作区内 pom.xml，自动识别模块结构；
- **Main Class 推断**：缺省时自动推断入口类；
- **构建引擎**：增量构建（只构建变更模块），运行时闭包分析；
- **启动管理**：优雅停止（超时自动升级进程树终止）、端口预检、启动横幅探测。

## Node.js 应用

- 按 `package.json` scripts 启动 dev server；
- 自动从输出中检测 Local/Network URL 与端口（兼容 Vite 8 彩色输出）;
- 端口被占用时预检并提示占用进程。

## 多服务环境

把一组服务定义为「环境」，一键启停整个环境（如「本地联调环境 = 网关 + 用户服务 + 前端」）。

## 日志与监控

- **日志引擎**：按服务流式输出、可检索、可导出；敏感信息（密码、密钥）落盘前自动脱敏；
- **健康探针**：Port / HTTP / TCP / Spring Boot Actuator 四种，持续监控服务存活；
- **端口管理**：查看端口占用进程、安全释放（见 [工具箱](Toolbox) 的端口查询）;
- **文件监听 → 增量构建 → 自动重启**：改完代码服务自动跟上。

## 模板与预设

- **Runtime 模板**：把服务配置存为模板复用；
- **启动预设**：按服务配置环境变量、JDK 覆盖、JVM/Node 参数（含 IDEA 风格 Spring Boot 启动参数预设）;
- **跨仓库依赖图**：模块依赖可视化，并与 Git 联动（运行中服务的危险操作有保护提示）。

## 常见场景

**「我要起整个后端联调」**：配置好多服务环境 → 一键启动 → 日志页盯启动横幅 → 健康探针全绿即就绪。

**「端口被占了不知道是谁」**：[工具箱](Toolbox) → 端口查询 → 输入端口 → 看到 PID / 进程名 / 路径 → 确认后终止。
