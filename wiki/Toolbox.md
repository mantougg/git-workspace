# 工具箱

侧边栏「工具箱」是内置的开发小工具集合：首页为卡片网格（带类型标签与搜索），点卡片进入工具；左侧列表按类型分组，可随时切换。目前内置 26 个工具：

## 网络

| 工具 | 说明 |
| --- | --- |
| 端口查询 | 查询端口占用进程（PID / 可执行路径），可一键终止释放端口 |
| 路由分流 | 双网卡分流：内网网段走网线、其余流量走 WiFi/热点（见下文） |
| IP 地址查询 | 查询 IP 地理位置与 ISP，可查本机公网 IP |
| 子网计算器 | 子网掩码、网络地址、广播地址、可用主机数，支持子网划分 |
| LAN 加密聊天 | 无需服务器的局域网 P2P 端到端加密临时聊天室，消息只存内存 |

## 关于路由分流（Windows）

适用场景：电脑同时接着网线（内网）和 WiFi/热点（外网），希望**内网网段走网线、其余流量走 WiFi**。

工作原理与注意事项：

- 读取网卡信息不需要管理员权限；**应用分流会触发 UAC 提权**（弹窗请允许）;
- 分流 = 外网卡 metric 调低（默认路由走 WiFi）+ 内网网段加**持久静态路由**（重启不丢）;
- 执行前会**展示全部命令原文**供审查，确认后才执行；
- 「恢复默认」删除静态路由并把网卡 metric 恢复为自动；
- 目前仅支持 Windows（macOS / Linux 待补）。
