# F-19 总览热力图未横向占满且悬浮无提示

| 项 | 值 |
|---|---|
| 优先级 | P1 |
| 状态 | ✅ 已完成 |

| 关联任务 | F-01b（热力图初版） |

## 问题描述

总览页（Dashboard）的提交热力图：

1. 没有横向占满 Panel 内容区——格子固定 12px，约 53 列合计 ~795px，
   宽屏下右侧留出大片空白；
2. 鼠标悬浮到小格子上没有任何信息提示（看不到日期与提交数）。

## 根因（已定位）

`src/components/repo/CommitHeatmap.vue`：

1. `.heatmap-grid { width: max-content }` + `.heatmap-cell { width: 12px }`
   —— 网格宽度由内容决定，不随容器拉伸；
2. 悬浮提示用的是原生 `title` 属性——在 Tauri WebView（WebView2 /
   WKWebView）中渲染不可靠且无样式，实测不弹出。

## 修复范围

- [x] 网格改为随容器横向占满：`grid-auto-columns: 1fr` + `width: 100%`，
  格子 `width: 100%; aspect-ratio: 1`（保持正方形、随列宽缩放）；
  图例行的小方块保持 12px 固定尺寸（与网格格子样式解耦）
- [x] 移除对原生 `title` 的依赖，实现组件内自定义悬浮提示（事件委托 +
  fixed 定位，单元素复用，371+ 格子不各挂 tooltip 组件）
- [x] 无日期（范围外补位格）不显示提示

## 验收标准

- [x] 任意窗口宽度下热力图横向占满 Panel 内容区，格子保持正方形
- [x] 悬浮任意有效格子显示「YYYY-MM-DD：N 次提交」，跟随鼠标、不闪烁
- [x] 窄窗口下格子等比缩小，不出现横向滚动条（或滚动行为与之前一致）
