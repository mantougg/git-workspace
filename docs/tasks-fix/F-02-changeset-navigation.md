## 问题描述

点击进入 Change Set 页面后，没有任何途径返回首页（无返回按钮 / 面包屑 / 侧边导航入口），只能重启应用或强退。

## 定位线索

- 路由：`src/router/`，Change Set 视图：`src/views/` 下 ChangeSet 相关组件
- 对照其他页面（如 Dashboard / Health）的导航方式，确认是路由未注册返回入口还是布局缺少导航组件

## 修复范围

- [ ] Change Set 页面提供明确的返回首页途径（返回按钮 / 面包屑 / 全局导航，与整体布局风格一致）
- [ ] 同步排查同类「进去出不来」的页面，一并修复（至少在时间线记录排查结论）

## 验收标准

- [ ] 从首页进入 Change Set 后，一步操作即可返回首页
- [ ] 浏览器历史式前进/后退（如有）不出现死循环
