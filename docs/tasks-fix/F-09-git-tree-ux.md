## 修复范围

- [ ] a. **非叶子节点行双击展开**：鼠标在节点整行双击应展开/收起子级，目前只能点左侧折叠箭头（不要求必须点在 label 或箭头上）
- [ ] b. **差异内容展示位置错误**：叶子节点双击展示差异内容，应该展示在树的**右侧**，且可**横向拖动改变宽度**（splitter）；现在展示在左侧把树覆盖了
- [ ] c. **节点右侧状态标签**：展示分支名称、XX 处变更、已修改、未变更等，使用 Naive UI Tag 组件，配语义化颜色（如已修改=warning、未变更=default、新增=success 等，具体配色实现时定并记录）
- [ ] d. **未跟踪文件勾选后 Add 暂存按钮仍灰色**：勾选 untracked 文件应激活 Add 暂存按钮
- [ ] e. **按钮/输入框禁用逻辑错误**：默认状态、勾选已修改文件、或勾选整个仓库时——归退、Graph、Diff、分支、Stash、Worktree 全部禁用，commit message 输入框与提交按钮也禁用。需重新梳理各操作的启用条件（按选中对象类型 × 文件状态矩阵），实现后在时间线记录启用矩阵
- [ ] f. **中间选择器隐藏**：用途不明、可用性存疑，先隐藏（保留代码注释，不删除）
- [ ] g. **展开全部 / 收起全部按钮无效**：点击后没有任何反应
- [ ] h. **无法返回首页**：与 F-02 同类，本页面也需要返回首页途径
