## 问题描述

打包后打开应用：只能看到左侧菜单，右侧内容区完全不可见。DOM 层面内容
其实存在（`#app` innerHTML ~82KB，总览页数据渲染正常），但视觉上看不到。

同次反馈的「exe 文件图标仍是旧图标」经排查为 **Windows Explorer 图标缓存**
（抠取 exe 内嵌图标与 `icons/32x32.png` 比对一致，已是 8-27 新版），与本任务无关。

## 根因

`AppShell.vue` 把 `SideNav`（`height:100%`）、内容区、`StatusBar` 直接放进
**列向** flex 容器：SideNav 按 `height:100%` 占满整列高度，flex-basis 为 0 的
内容区被压缩到 **0 高**。CDP 几何探针实测（1829×1072 窗口）：

- sidenav: `{x:0, y:0, w:188, h:1048}` —— 视觉上是「左侧菜单」
- content: `{x:0, y:1048, w:1829, h:0}` —— 0 高，被挤出可视区
- statusbar: `{x:0, y:1048, w:1829, h:24}`

spec（desktop-skin-plan §5.1）本就是行向骨架图，属 D-03 实现偏差。

## 修复

`AppShell.vue` 增加 `.app-shell-body` 行向（`flex-direction: row`）容器承载
SideNav + 内容区，StatusBar 保持通栏底部。

- [x] 安装后实测：总览等视图内容可见
