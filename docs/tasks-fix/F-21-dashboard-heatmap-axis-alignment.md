## 问题描述

概览页（Dashboard）：

1. 提交热力图只有格子网格，没有横轴（月份）与纵轴（星期）坐标标签；
2. 摘要行中「未跟踪」与「有变更」「冲突」等可点击项的数值不在同一水平线上。

## 根因（已定位）

1. `src/components/repo/CommitHeatmap.vue` 初版未实现坐标轴；格子流自带日期
   （`YYYY-MM-DD`），行列语义明确（列 = 周、行 0 = 周日），可直接推导坐标。
2. `DashboardView.vue` 的 `.summary-item.clickable` 有
   `padding: var(--gw-space-1) var(--gw-space-2)`，不可点击项（「未跟踪」，
   `jumpable: false`）没有 padding——两类项盒子高度不同，baseline 错位。

## 修复范围

- [x] 热力图加横轴：月份标签行，按「列首格月份相对上一列变化」在对应列左缘
  定位（`left = col/cols * 100%`），与网格左缘对齐（左缩进 = 纵轴宽）
- [x] 热力图加纵轴：星期标签列（标 一/三/五），`grid-template-rows:
  repeat(7, 1fr)` + 同 3px 间距，行高恒等于格子行高，逐行对齐
- [x] 月份行/星期列不挂 `data-tip`，不影响 F-19 的悬浮提示事件委托
- [x] `.summary-item` 的 padding/border-radius 上移到基础类，可点击与不可
  点击项统一，hover 背景仍只属 clickable

## 验收标准

- [x] 热力图上方显示月份标签、左侧显示星期标签，且随窗口宽度缩放保持对齐
- [x] 悬浮提示、横向占满（F-19）行为不回归
- [x] 摘要行所有项的数值在同一水平线上，可点击项 hover 效果不变
- [x] `pnpm build`（vue-tsc + vite）通过
