## 问题描述

在应用底部增加一栏，展示作者与版本说明，格式示例：`v0.1.0 by mantougg`。

- `v0.1.0`：当前版本号（与 `package.json` / `tauri.conf.json` 版本保持一致，取单一数据源，不要两处手写）
- `mantougg`：开发者名字

同时需要把「底部展示 版本号 by 作者」作为一条规则写入根目录 `AGENTS.md`，让后续开发遵守。

## 修复范围

- [ ] 全局布局底部增加版本栏，所有页面可见
- [ ] 版本号从配置单一数据源读取（构建期注入或运行时读取，避免硬编码漂移）
- [ ] 作者名可配置
- [ ] 根目录 `AGENTS.md` 增加此规则说明

## 验收标准

- [ ] 应用底部常驻展示 `vX.Y.Z by <author>`，版本号与实际发布版本一致
- [ ] `AGENTS.md` 中新增对应规则条目
- [ ] 底部栏不遮挡既有内容、不影响既有布局交互
