## 问题描述

应用关闭再打开时，左下角应该回到上次关闭时选中的工作区，而不是重新落到默认第
一个工作区。这个状态需要跟随 StatusBar 的工作区槽位恢复，不能只留在内存里。

## 定位线索

- src/stores/workspace.ts 目前只在内存中维护 currentWorkspace
- src/components/shell/StatusBar.vue 切换工作区时直接改 currentWorkspace
- src/views/WorkspaceManageView.vue 已经在用 selectWorkspace
- 各依赖视图都通过全局 workspace store 派生当前工作区

## 修复范围

- [ ] 持久化当前选中的 workspace 标识
- [ ] 启动时优先恢复上次选中的 workspace
- [ ] 工作区不存在或被删除时自动回退到可用工作区
- [ ] 保持 StatusBar 与所有依赖视图同步

## 验收标准
