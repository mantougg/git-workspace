## 问题描述

首页应定位为数据概览页，以数据卡片和图表为主，而不是现在的形态。

## 修复范围

- [ ] a. 仓库数量和状态卡片：展示当前工作空间下仓库总数及各状态（正常 / 异常 / 扫描中等）的数量分布
- [ ] b. 提交热力图：当前工作空间下、当前用户（`git config user.name` / `user.email` 匹配）在所有仓库的提交汇总热力图，使用 Naive UI 的热力图相关组件（无现成 Heatmap 组件时用 ECharts calendar heatmap 或自行实现，需在文档记录选型）
- [ ] c. 健康检查入口移到首页可直接执行；**执行时不得弹出 cmd 终端窗口**（Windows 子进程必须设 `CREATE_NO_WINDOW`，参照 `process/streaming.rs` 与 `AGENTS.md` 平台规范 §3）
- [ ] d. 展示「创建的应用」（Runtime 侧已创建的应用列表卡片，可点击进入详情/启动）

## 验收标准

- [ ] 首页首屏包含 a–d 四类卡片/图表，数据来自现有缓存 / IPC，打开首页不触发全量重扫
- [ ] 热力图数据准确（按提交作者过滤、按日聚合），提交多的日期颜色深
- [ ] 在 Windows 上执行健康检查全程无 cmd 窗口闪现
- [ ] `pnpm build` 与相关前端类型检查通过
