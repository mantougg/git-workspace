# 终端功能全局开发约束（所有 TM-XX 任务必读）

> 本文是终端任务的**横切硬规则**，叠加在根目录 `AGENTS.md`「平台兼容性开发规范」之上；
> 若冲突，在任务文档显式说明原因与边界。架构/契约类基准见 [../terminal-feature-plan.md](../terminal-feature-plan.md)。

## 1. PTY 路径特有规则

- **禁止在 PTY 路径使用行读取与 lossy 解码**（`read_line` / `String::from_utf8_lossy`）：PTY 是字节流，多字节字符可跨块。传输用 base64，前端解码为 `Uint8Array` 交给 xterm（其解析器可处理跨块序列）。
- **Windows ConPTY 不得叠加 `CREATE_NO_WINDOW`**：spawn 由 portable-pty 内部管理，`Command` 路径的 `creation_flags` 约定不适用于此；代码注释中说明另一平台行为。
- **unix PTY 子进程天然独立 session**（forkpty 语义），满足 AGENTS.md 的 killpg 约定；**关闭会话必须复用 `process/kill_tree.rs`**（先 `terminate_process` 组 SIGTERM，超时升级 `kill_process_tree`），禁止另起 kill 实现。
- **Shell 探测必须走 `find_in_path`**（`.exe → .cmd → .bat → 裸名`），探测顺序以方案 §5.1 为准；探测不到时返回可行动错误，禁止裸名 `Command::new("powershell")` 兜底。

## 2. IPC 与事件

- 事件名**禁止含 `.`**（F-15）；统一 `terminal_*` / `git_op_output` snake_case 前缀，payload serde camelCase。
- 高频输出必须**预聚合**：PTY reader ≤50ms 或 ≥8KiB flush；前端 xterm 写缓冲合并 chunk。
- 契约（命令名/参数/事件 payload）以方案 §4.2 为唯一基准；前后端任意一侧需要变更时先改 spec。

## 3. 安全

- 终端原始流**一期不落盘、不过脱敏器**（用户自己的 shell 会话）；但镜像进面板的 runtime 输出沿用既有已脱敏 `LogLine`。
- 「在终端中启动」写入命令前必须过脱敏检查：`LaunchPlan.preview` 含敏感 env 时禁用该模式并提示。
- Secret 永不跨 IPC（既有规则不变）。

## 4. UI 与交互

- 样式全部用 `--gw-*` tokens（含 xterm 主题取色），禁止硬编码色值/像素/字号；等宽文本用 `--gw-font-mono`。
- 面板骨架仿 `TaskPanel.vue`（底部 drawer、可拖高 240px~85vh）；新面板用 `Panel`/`PanelHeader`/`Toolbar` 骨架组件。
- 面板全局唯一开合入口是 **StatusBar 槽位**；快捷键统一走命令注册表（`src/commands/`），禁止视图内私绑。
- `@xterm/xterm` 组件懒加载（`defineAsyncComponent`），不拖慢首屏。

## 5. 性能与资源

- 每 tab 渲染缓冲设上限（沿用 runtime 5000 行级思路）；tab 隐藏时暂停 xterm 渲染（保留数据）。
- PTY 会话在应用退出时全量清理（teardown 钩子）；面板重开以 `terminal_list` 的存活会话为准恢复。
- 高频路径避免每行一次 IPC（见 §2 批量规则）。

## 6. 测试

- 解析/编解码/候选序列保持纯函数可单测；系统调用集中单一入口。
- 环境相关集成测试（无 shell/无工具链）探测不到就 skip 并打印原因，不硬失败；产品逻辑返回可行动错误。
- 三平台手动冒烟 checklist 以 TM-03 验收标准为准；路径断言先归一化（AGENTS.md §5）。
