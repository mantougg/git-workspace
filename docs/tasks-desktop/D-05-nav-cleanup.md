## 目标

把所有视图从「Web 站点页面」收敛为「骨架内的面板」：导航按钮、自绘返回、视图内工作区选择器、任务按钮全部移除，工作区切换全局唯一入口收编 StatusBar。

## 需求范围

- [ ] 各视图 toolbar 移除指向其他视图的导航按钮（逐视图按 §5.4~§5.9 的移除清单执行，如 Dashboard 7 个导航按钮、RepositoryList 5 个、RuntimeDashboard 3 个）
- [ ] 各视图自绘「返回」按钮移除，统一走骨架返回（任务型页面验证可正确回到来源页）
- [ ] 各视图「任务 (n)」按钮移除（D-04 已收编 StatusBar）
- [ ] 各视图工作区选择器移除，视图数据加载改为响应全局 store 的当前工作区（StatusBar 切换器驱动）
- [ ] Dashboard 的「添加工作区」「工作区管理」入口迁移至 SideNav 设置组的工作区管理页内
- [ ] 不动任何视图的业务逻辑与 IPC 调用（纯导航/壳层清理）

## 验收标准

- [ ] 全部 22 个视图无导航按钮、无自绘返回、无工作区选择器、无任务按钮
- [ ] **F-02 回归通过**：Change Set 等任务型页面可正常返回来源页
- [ ] StatusBar 切换工作区后，各视图数据正确重新加载（逐视图过一遍）
- [ ] `pnpm build`（含 vue-tsc）通过
