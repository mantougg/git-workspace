## 目标

用真实样例把 MVP 闭环在双平台验收一遍，回归安全项，同步文档；本任务完成后 Node MVP 整体可交付。

## 需求范围

- [ ] Vite 样例工程闭环：发现 → 建配置 → 启动 → 端口正确识别 → 日志流 → 停止；Windows + macOS 各一次
- [ ] **进程树回归**：`cmd /C npm run dev` 的孙子进程（vite）经 `kill_tree` 整树终止，Stop 后端口真实释放（Windows 重点）
- [ ] 错误路径验收：`node_modules` 缺失 / script 不存在 / pm 缺失 → 三类可行动提示
- [ ] Secret 脱敏回归：`environment` 含 `TOKEN`/`API_KEY` 时日志 / preview / UI 三处一致打码
- [ ] 旧 springBoot 配置全链路回归（启动/停止/重启/日志）
- [ ] 文档收尾：根 `AGENTS.md` 平台规范补「npm.cmd 必须 find_in_path + cmd /C」参照实现条目；设计文档状态更新；README 总表收尾

## 架构 / 性能注意点

- 验收样例固定为真实 Vite 模板工程（`npm create vite` 产物，入 fixtures 或临时目录，不进用户项目）。
- 所有验收结论附验证命令与输出摘要，记入时间线（可审计）。
- 发现 MVP 外缺陷：不随手修，登记到 N-08/N-09 或 docs/tasks-fix/。
