## 目标

把 Runtime 依赖关系以图形化方式呈现：树/图视图展示模块依赖，按依赖来源（Source / Local Maven / Remote Maven）着色，并与 Runtime Scope 联动。

## 需求范围

- [x] 依赖树/图视图（§45）：层次展示应用 → 模块 → 库依赖
- [x] 来源着色与图例：Source（含相对路径）/ Local Maven / Remote Maven 三种状态区分
- [x] 与 Runtime Scope 联动（R-13）：图中勾选/排除模块直接调整 Closure
- [x] 节点详情：GAV、版本、来源、所在仓库/路径
- [x] 大图性能：100+ 模块时布局分层 / 折叠 / 虚拟化，交互不卡顿
- [x] 过滤与搜索：按模块名/坐标过滤子图

## 架构 / 性能注意点

- 数据一次性从 R-02 图查询组装，前端只做展示与交互；大依赖图分页/折叠加载，不全量铺 DOM。
- 布局算法选轻量方案（层次树优先），不引入重型图库除非必要——选型需在时间线记录理由。
- 颜色同时配文字/图标区分，不单独依赖色相（可访问性）。
