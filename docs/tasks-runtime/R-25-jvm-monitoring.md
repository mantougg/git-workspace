## 目标

为运行中应用提供 JVM 级可观测性：内存 / GC / 线程等指标采集与展示，支持 JMX 连接，形成 Runtime Metrics 面板。

## 需求范围

- [ ] JVM 指标采集：Heap / Non-Heap 内存、GC 次数与耗时、线程数、类加载数、Uptime
- [ ] 采集通道：JMX（应用侧开启/自动附加）或 Spring Boot Actuator metrics（存在时优先）
- [ ] Runtime Metrics 面板：实时曲线（内存/GC/线程），历史窗口可回看
- [ ] 指标落盘：低频采样入 SQLite，供趋势分析；容量有上限
- [ ] 告警提示：内存逼近上限 / GC 频繁等基础阈值提示（可选）
- [ ] 与 R-16 Health Check 数据整合到同一应用详情视图

## 架构 / 性能注意点

- 采样频率保守（秒级起步、可配置），采集自身开销计入资源预算；应用停止即停采。
- JMX 连接失败降级到 OS 进程级指标（R-10 已有 CPU/内存），不构成硬依赖。
- 前端图表渲染遵守渲染预算：降采样 + 虚拟化，原始序列不直接全量渲染。
- 指标存储走 T-03 数据层约定（批量写入、保留窗口清理）。

## 验收标准

- [ ] 样例应用运行中内存/GC/线程指标准确实时展示
- [ ] JMX 不可用时自动降级且界面有标识
- [ ] 指标历史可回查，存储占用有界
- [ ] 采集开销可忽略（Benchmark 记录）
